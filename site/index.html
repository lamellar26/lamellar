lamellar alpha

Armor for small local models. A small, readable, fully offline agent toolkit that checks its work before handing it to you.

curl -fsSL https://lamellar.org/install.sh | sh

Linux and macOS. No curl? wget -qO- https://lamellar.org/install.sh | sh. Windows is not supported yet. Want to read it first? install.sh is plain shell.

What it is

  • An agent that runs on your own machine. It talks to a local model through Ollama, runs shell commands and edits files in its working directory. Nothing leaves your computer.
  • Armor. A lamellar is armor made of many small plates. Here the plates are rules: your requirements are stored, every answer is checked against them before delivery, and failed answers are sent back for a rewrite.
  • Guard rails. Commands that touch credentials, system config, scheduling or services stop and ask a human first. Each command has a time and memory limit.
  • Small and readable. About two thousand lines of Python, standard library only. Long conversations are compacted inside the core, so it keeps working on a 16 GB card.
  • A web interface included. Open http://localhost:8102/, or connect Open WebUI or any OpenAI-compatible client to /v1.

What the installer does

  1. Checks for Python 3.10+, installs it if missing.
  2. Installs Ollama with its official installer if missing.
  3. Reads your GPU memory and picks a model that fits.
  4. Downloads the model and sets the right context length.
  5. Writes the config to ~/.lamellar, starts the web interface and opens your browser.
  6. Runs lamellar doctor, which checks everything and says how to fix anything that is wrong.

It never installs GPU drivers. Running it again upgrades the code and keeps a backup of your config.

lamellar doctor
